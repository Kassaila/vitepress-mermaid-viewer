# Contributing

Thanks for your interest in contributing to vitepress-mermaid-viewer!

## Requirements

- Node.js >= 22.0.0
- npm >= 9.0.0

## Setup

```bash
git clone https://github.com/Kassaila/vitepress-mermaid-viewer.git
cd vitepress-mermaid-viewer
npm install
```

## Quick Reference

```bash
npm run build          # Production build (ESM + CJS + types)
npm run build:dev      # Development build (with sourcemaps, no minify)
npm run dev            # Build in watch mode
npm run lint           # ESLint check
npm run lint:fix       # ESLint auto-fix
npm run format         # Format code with Prettier
npm run check:all      # Full validation (format + lint + types + build)
npm run docs:dev       # VitePress dev server
npm run docs:build     # Build documentation site
npm run docs:preview   # Preview built docs
```
